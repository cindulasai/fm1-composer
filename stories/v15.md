# v15 — energy / swing macros, setlists (FM-1)

### US-45 — ENERGY and SWING macros while a piece plays
F: F41 · Files: app/firmware/src/player.c, app/firmware/src/composer.c, app/tests/steps_test.c, app/tools/tests/test_macros.py, app/README.md
- [ ] 45.1 [unit] player: energy e (−50..+50) plays every note at vel × (100 + e) / 100, rounded, clamped 1..127 (vel 1 never silent, 127 stays 127 at +50); e = 0 → the bytes' velocities exactly; macro swing s (0..100) swings every channel as if its own swing were max(its own, s); s = 0 → each channel's own swing exactly (US-25 tests unchanged)
- [ ] 45.2 [e2e] emulator (host), PLAYER, a piece playing: SEL held + KNOB3 / KNOB4 move ENERGY / SWING; the footer shows `ENERGY +50` / `SWING 100`; the rendered audio is > 1.5× the RMS at +50 than at −50, and notes on the 2nd 1/16 of each beat start 45–80 ms later at SWING 100 than at 0 (half a 1/16 at 120 BPM)
- [ ] 45.3 [hostile] turning past +50 / 0 / 100 → stays at the end (`ENERGY +50`, `SWING 0`, `SWING 100`); SAVE while macros are set → the pulled piece byte for byte as without; opening another piece (HOME, PLAY) → from 0 again (+1 shows `ENERGY +1`); a turn while stopped → shown, and heard on PLAY (quieter at −50). A live send and STOP / PLAY keep them (a performance carries on)

### US-46 — Setlists: pieces played back to back
F: F42 · Files: app/firmware/src/composer.c, app/firmware/src/ui.c, app/tests/xfer_host.c, app/tools/tests/test_setlist.py, app/README.md
- [ ] 46.1 [e2e] LIBRARY (host): ARP adds the selected piece (`SET 1: high`, `SET 2: low`, `SET 3: mid`; LIBRARY's footer, cleared by moving the selection); SEQ plays them in that order, each heard (its pitch) in its own 2 s, sound continuing across the hand-over (a live send at the end); the footer `SET 1/3 high` … `SET 3/3 mid`, then `SET DONE`, silence after (the last plays once)
- [ ] 46.2 [e2e] the set is kept across a power-off (HOST_FLASH: a new run, SEQ → `SET 1/3 high`); GLO → `SET CLEARED`, then SEQ → `SET IS EMPTY`; a piece deleted with `fm1c delete` leaves the set (`1 PIECE LEFT THE SET`, `SET 2/2 mid`, `SET DONE`)
- [ ] 46.3 [hostile] SEQ with an empty set → `SET IS EMPTY`; 17 adds of the same piece → `SET 16: high` then `SET FULL (16)`; STOP mid-set → `STOPPED`, HOME, SEQ → from the start (`SET 1/3 high`); a corrupt saved set (count 999) → empty, no crash. (A piece that fails its check is skipped with `SKIPPED name`: the library checks every piece when it is stored, so no test can store a bad one)
