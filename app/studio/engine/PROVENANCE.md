copied unchanged from text2midi_v2 (same owner, github.com/cindulasai/text2midi_v2) at commit:

commit 9540490610363cb11a7ebf71a8e66065751470bb

when that repository is on this computer. `Cargo.lock` started as text2midi_v2's (the same versions)
and now also locks the studio crate's own dependencies. To update: copy a newer commit the same way, regenerate this list.
